Documentation API — Intégration serrures intelligentes
v1.0 — REST / JSON

Cette API permet de connecter HotelSuite ERP à tout système de serrures compatibles (ASSA ABLOY Vingcard, Dormakaba, SALTO Systems, ZKTeco, etc.) via des endpoints REST sécurisés. Authentification par Bearer Token JWT.

🔐 Authentification
POST/api/v1/auth/token
Obtenir un token d'accès pour les appels API (validité 8h)
// Request body { "client_id": "hotelsuite_erp", "client_secret": "your_secret_key", "grant_type": "client_credentials" } // Response 200 OK { "access_token": "eyJhbGciOiJIUzI1NiIs...", "token_type": "Bearer", "expires_in": 28800 }
💳 Encodage de carte
POST/api/v1/cards/encode
Encoder et attribuer une carte magnétique/RFID à une chambre
// Request body { "room_id": "204", "guest_name": "M. Koné Séydou", "check_in": "2025-06-05T14:00:00Z", "check_out": "2025-06-08T12:00:00Z", "card_type": "guest", "copies": 2 } // Response 201 Created { "card_uid": "A3:F2:1B:9C", "encoded_at": "2025-06-05T13:45:00Z", "status": "active", "lock_command_sent": true }
📋 Journaux d'accès
GET/api/v1/access/logs?room_id=204&date=2025-06-05
Récupérer l'historique des accès pour une chambre ou toutes les portes
// Response 200 OK { "logs": [ { "timestamp": "2025-06-05T15:12:33Z", "room_id": "204", "card_uid": "A3:F2:1B:9C", "guest": "M. Koné Séydou", "status": "granted", "door": "main_entry" } ], "total": 1 }
🚫 Révoquer une carte
DEL/api/v1/cards/{card_uid}/revoke
Désactiver immédiatement une carte (perte, vol, checkout anticipé)
// Response 200 OK { "card_uid": "A3:F2:1B:9C", "revoked_at": "2025-06-06T09:00:00Z", "lock_updated": true, "message": "Card successfully revoked on all locks" }
🔔 Webhooks (push temps réel)
POST/api/v1/webhooks/register
S'abonner aux événements d'accès en temps réel (WebSocket ou HTTP push)
// Événements disponibles : "access.granted" — Ouverture réussie "access.denied" — Carte refusée / invalide "card.expired" — Tentative avec carte expirée "door.forced" — Porte forcée (alarme) "battery.low" — Batterie serrure faible // Systèmes compatibles : ASSA ABLOY Vingcard Allure / Essence Dormakaba Ambiance / Saflok SALTO KS / XS4 One ZKTeco ML10 / ML100
